# mentions

## Rules
- A test unit is an outermost metrics unit (see `metrics`) of a discovery Test file, or one inside an inline `#[cfg(test)]` region of a Rust Source file (when `[tests].count_inline_tests_as_refs`, default on). A Rust macro call at item level outside every unit (`rgtest!(name, …)`, `t!(…)` beside a helper fn) is a unit of its own. A unit's range takes in the decorators or outer attributes above it (`@pytest.mark.parametrize("cls", [Widget])`, `#[case(Foo::Bar)]`). A Test file with neither a unit nor a macro call is one unit; so is a region with none (`#[cfg(test)] use …`). A unit nested in another counts toward the enclosing one, never on its own.
- A unit's identifier set is the text of its identifier tokens: Rust `identifier`, `field_identifier`, `shorthand_field_identifier`, `type_identifier`; Python `identifier`; TS/TSX/JS `identifier`, `property_identifier`, `shorthand_property_identifier(_pattern)`, `type_identifier`. Type positions count (`let c: Config = Config { .. }` names `Config`). String literals never count: a subcommand name in `run("status")` is not a mention.
- A Source file's symbols are its outermost metrics units (functions and methods, by their own name: `Owner.method` matches `method`) plus a small per-grammar walk that never enters a function body: Rust `struct`/`enum`/`union`/`trait`/`type`/`const`/`static` items at any module depth; Python `class` definitions and module-level `UPPER_CASE = …` consts; TS/JS classes, interfaces, type aliases, enums and top-level non-function `const`/`let` declarators. Symbols inside inline test regions, Rust methods of `impl Trait for Type` blocks (named via the trait), call-site-named units (`app.post('/x')`) and names shorter than `[tests].min_name_len` (5) are left out.
- A symbol is public when: Rust, it carries a visibility modifier (`pub(crate)` counts; a bin crate's API is crate-visible); Python, it is a module-level def, class or const whose name and file basename do not start with `_`; TS/JS, it is an exported function, class or arrow/function const. Methods, interfaces, type aliases and plain consts are matchable but never public.
- A test unit references file F iff its identifier set contains any symbol of F; a name defined in two files marks both. `test_units(F)` is the number of referencing units, split into `test_file_units` and `inline_units`; a symbol is mentioned when any unit's set holds its name; `unmentioned[]` lists F's public symbols mentioned by no unit, in line order.
- The Source side (symbols, inline unit sets) is computed on the metrics pass's tree through `metrics::analyze_all_with`; only Test files are parsed by this pass. `scry mentions` parses both, prints the unit totals, the files with the fewest units first, and each file's unmentioned public symbols with line ranges; `--json` is the index.
- `[tests].min_name_len` bounds both sides: shorter identifiers are never collected and shorter symbols never indexed, so `run`, `new`, `parse` cannot make every file look tested.
